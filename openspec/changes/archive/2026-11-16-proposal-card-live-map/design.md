## Decisions

**Project-lead decision, 2026-11-16.** The picture leaves the page and is made on demand. The page shows a live map with hover facts. Redirect facts come from stored data, not a simulation on hover.

**Landscape picture.** Layout width 1,200 px, saved at 1.5 times (1,800 px wide), which is fewer pixels than the old 800 by 2,500 at 2 times, so the 450 KB cap is met at the first quality step more often. At the card's width on a desktop (about 860 px) the layout shrinks to 0.72, so type of 17 layout px or more reads at 12 px or more; nothing is set below 16. The text column width is searched between 38% and 44% of the width and the map fills the height of the taller column (minimum 560 px), so a short list gives a wider map and a long list a taller picture. The cap is 1,080 px: past it, change lines shorten to the first clause (`firstClause`, the same cut the preview descriptions use), then to "and N more" with at least one change named. The card keeps the full list. The QR code goes in the first corner of the map, in the order bottom right, top right, bottom left, top left, whose stamp-sized square holds no colored block, mark, street name or label (`freeCorner`, sampling the drawn geometry); if none is clear it goes under the text column and the map is laid out again. The module size stays 3 layout px (4.5 px in the file) because a larger code would take a quarter of the map's width.

**Measured streets only.** The map and the picture color only side streets inside the study area (`blockMeasured`, `src/lib/scope.ts`). Bounding streets and the rest of the network are faint context.

**Per-block facts.** The file's `picture` holds through cars an hour per link, today and with the package, averaged over the proposal's confirmation seeds. The hover shows exactly that, labeled as through cars, the period and the runs. All cars on a block appear only for the one block per period the file records (`allTraffic.largestIncrease`); every other block says all cars are not in the file.

**Light map per card.** One inline SVG per card, drawn when the card nears the screen, from the network geometry already loaded. No WebGL. Hit areas are transparent wide strokes on every measured block; changes are groups with a transparent hit circle. Mouse hover sets a transient selection and shows a small tip; click and tap pin the selection; Escape clears it. The same selection is driven by the table and list buttons, which are focusable, so the map needs no keyboard access of its own. The selected street or change is also drawn with a heavier halo or a dashed ring, so the cue is not color alone.

**Stored redirect data.** `displacement` in `src/lib/redistribution.ts` already follows the baseline's through trips that drove a closed movement into a scenario's run, and the closure sweep uses it. The generator runs today's traffic and the package once per seed (the proposal's confirmation seeds, the picture's period, the group's run length) and applies `displacement` once per traceable intervention, using that intervention's closed movements alone as the selector, against the package's run. Cohort: through trips only (neither end in the study area), because those are the cars the proposal sets out to move. Per intervention it stores cars an hour that used the movement, where they were in the package's run (newly driving another side street; staying on bounding streets or streets they already used; removed; no route; still waiting; not followed), up to four routes by cars an hour with their links near the closure, and up to four receiving blocks. A file carries the proposal's link, period, seeds, and the hashes and simulator it was made on, and `redistributionVerdict` refuses it on any mismatch with the card's own figures or with what is loaded. The data are an accounting of simulated trips in an uncalibrated model, and the panel says so.

**Why not per-click live runs.** A traced hour with ten seeds takes minutes. Hover must answer at once, so the data are computed beforehand and published with the other data files.

## Risks

The generator is slow (about 70 traced runs for six packages). It skips current files. The worker needed `redistribution/` added to the names it serves.
