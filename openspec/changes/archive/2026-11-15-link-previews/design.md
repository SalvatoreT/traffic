## Decisions

- **Slug**: `<group id>-<8 base-36 characters of a 53-bit hash of group, period, demand scale and sorted items>`. It ignores the proposal id (p1, p2), which changes when a search ranks packages differently, so a re-published package keeps its address. Collisions throw; a package listed twice in a group keeps one entry. The page and the Node tools share `src/lib/share-path.ts`, so there is no separate index to keep in step.
- **Address bar**: `/p/<slug>` resolves client-side from the proposals file, then the page behaves as its `#v1;...` link does (stored result included) and the address bar becomes the normal scenario link. Back, Forward and the tabs then work as before. An unknown slug opens Proposals with "That proposal is no longer published."
- **Copy link**: cards gain "Copy link" and the picture's QR code uses the share path. "Copy link to this scenario" uses it when scenario, period and default demand equal a published proposal of a group whose inputs are current; otherwise it stays the `#v1` link.
- **Cards**: new 1200x630 layout (map right, text left, nothing under 28 px) sharing the picture's map drawing (`mapSvg`, with a size boost, no labels). Proposal cards show the change in through cars for the picture's period, from the same data and caveat text as the app.
- **Rendering**: `@resvg/resvg-js` (MPL-2.0, native, offline), Inter Regular and Bold subsets (about 50 KB each, OFL) in `tools/fonts/`, no system fonts, widths measured with `opentype.js` from the same files, JPEG via `jpeg-js` (cards are about 100-140 KB; PNG would be about ten times larger). Output is deterministic.
- **Staleness**: a group computed on other network or demand, a proposal with no picture, or a stored baseline for other inputs gets no card of its own; the generator lists what it skipped, and generic cards cover the rest.
- **Worker**: for `/`, tab paths and `/p/*` it fetches the shell, strips the shell's own title, description, canonical, Open Graph and Twitter tags and inserts the path's tags (a string rewrite, since HTMLRewriter is not available in the Node test environment). Values are HTML-escaped. The index (`areas/og/index.json`) is cached in memory for 60 s; without it the shell is served untouched. Cards at `/og/<name>-<hash>.jpg` are immutable for a year because the hash is in the name; the HTML is revalidated every time.
- **Dev**: the same Worker runs under `npm run dev`, reading `public/data/og/`.
