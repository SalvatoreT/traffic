## Root cause of the flicker

`Simulation::link_stats` (crates/sim/src/sim.rs, `link_stats`) divided counts from ten 30 s bins (`NBINS`, `BIN_S` in params.rs) by the window length, so every value was a five-minute rolling rate. One vehicle on a link is 12 veh/h. `changeIntensity` in src/lib/change.ts compared the baseline-minus-scenario difference to a hard band (7.5 veh/h for cut-through) and returned 0 inside it, so a street whose difference was one vehicle jumped from 0 to a full color step and back as vehicles left the window. Without interventions the same window made a street go from a color to "no data" gray whenever its five minutes were empty. Reproduced in Chrome at 20x: a link read 0.13, 0, 0.13, 0, 0.13 across consecutive samples.

## Decisions

- D1. Average over the run so far, not a longer trailing window. A trailing window still quantizes and still drops traffic as it slides; the cumulative average only changes by (new evidence) / elapsed time, so steps shrink as the run goes on. Cost: a street's value lags a mid-run change. The legend states "averages over the simulated time so far". Elapsed time is floored at 1 s, and counting starts at t = 0 (the settle interval before it is not counted).
- D2. Keep the rolling `link_stats` for native callers (the proposal search samples it) and add `run_link_stats`; the WASM `linkStats` export returns the run average. The TS mock already averaged over the run.
- D3. Baseline and scenario are stepped by the same `secs` in one worker call and reported in one message, so the difference is always taken at the same simulated time. A restart counter on the worker's reports drops messages that were in flight before a reset.
- D4. Soft threshold. Difference d maps to sign(d) * max(0, |d| - band) / (top - band), clamped. It is zero inside the band and reaches 1 at the top of the scale, so there is no jump at the band edge. The noise band stays an ASSUMPTION (5% of the top). Arrow marks still start at the same intensity.
- D5. Instant runs in slices of at most 40 ms of wall time, 15 simulated seconds per step call, and yields between slices so pause and speed changes apply at once. The engine steps a fixed 0.25 s and accumulates remainders, so chunking cannot change results; a unit test checks it with the mock and the browser check compares Results and per-street values against a 60x run. Speed is not stored in scenario links.
- D6. Export reads the WebGL canvas inside the map's render event (no `preserveDrawingBuffer`), at 2x through `setPixelRatio` when the screen is below that, then restores it. The vehicle layer is painted again onto the export canvas at 2x with the same routine the page uses; intervention badges are drawn from the same colors and shapes as the page's badges. Caption band above, legend and credit below, so nothing hides the map.
- D7. The context menu opens only on the map itself, not on its controls, pop-ups or the rest of the page. It uses menu roles, moves with arrow keys, closes on Escape, Tab or an outside press, and returns focus to where it was.
